# Security policy

Report vulnerabilities through GitHub private vulnerability reporting. Do not publish exploit details, credentials, repository contents, or unredacted tool output in an issue.

Guardian is defense in depth. A bypass in a built-in deny rule, a canonical-value redaction failure, or a secret appearing in logs should be treated as a security vulnerability.

The project is pre-release. Security fixes target `main` and the most recent npm prerelease after publishing begins.
